# 黑客世界 Hacker World · 网页自走棋

原创科幻自走棋游戏：组建数字战队，在虚构网络空间与 AI 对手自动攻防。
**全部攻防均为游戏内虚构机制，不连接真实目标，不执行真实网络攻击。**

## 启动方式

```bash
cd hacker-world
npm install
npm run dev        # 打开 http://localhost:5173/
# 或只看构建产物：
npm run build && npm run preview
```

离线单文件版（已生成，可直接用浏览器打开，无需服务器）：
`dist-single.html` —— 由 `dist/` 内联 CSS/JS 生成，功能与构建版一致。

## GitHub Pages 自动部署

`.github/workflows/deploy-pages.yml` 会在推送到 `hacker-world` 分支时自动构建并发布。
首次使用需在仓库 Settings → Pages → Build and deployment 里把 Source 改为 **GitHub Actions**，
发布后地址为 https://xieyuke2026-cpu.github.io/muse/（构建时资源路径已设为 `/muse/`）。
注意：免费账号的 GitHub Pages 通常只支持公开仓库；如果你的 muse 仓库是私有的且 Pages 不可用，
需要把它改为公开或升级账号方案。

## 操作指南

1. 点击商店卡片招募程序（扣算力，进待命区 9 格）。
2. 点击待命区程序选中，再点击部署区空格部署；选中后点另一格可交换位置。也可以直接点「一键部署全部」（防御程序自动站前排、远程站后排），或在右侧点「部署选中程序到空位 / 收回待命区」。选中待命区程序后，可部署的空格会以黄色虚线框高亮，顶部还有当前步骤提示。
3. 敌我区分：我方青色边框 + 我字徽标 + 绿色血条，敌方红色边框 + 敌字徽标 + 红色血条；部署区我方为青色底、敌方为品红/红色底。程序立绘来自公开网页搜索，来源见 ASSETS.md。
4. 界面布局参考崩坏：星穹铁道「货币战争」实机版式（金币商店、利息、等级=人口、羁绊加成的自走棋模式）：左侧羁绊竖栏、上方居中商店、中部棋盘、下方备战区、左下等级+买经验、右下金币、右侧圆形刷新+橙红 Battle 大按钮，整个准备阶段在一屏内完成，页面本身不滚动。商店卡边框颜色即费用（灰1/绿2/蓝3/紫4/金5），选中单位为亮青边框+上方倒三角；战斗开始后商店/备战区整屏消失。注意：本游戏棋盘为 8×4 部署格（原游戏为上场/场外分区，无格子走位），与原游戏机制并不完全相同；未复制原游戏美术，立绘与界面均为复刻设计。
3. 点击「发起入侵」：双方自动攻防（移动、寻敌、普攻、能量攒满放技能、护盾/治疗/持续伤害/眩晕、死亡判定）。
4. 胜负结算：伤害 = 3 + 存活单位数，扣对方核心完整度；核心先归零者败。超时 60 秒按剩余生命判定。
5. 回合结束自动发收入并进入下一回合，AI 阵容随回合变强。
6. 右侧可卸载选中程序、给选中程序加载模块；底部可刷新商店（2 算力）、购买经验（4 算力 = +4 经验）。
7. 「保存 / 读取」用浏览器本地存储；「重新开始」开新局。

## 核心规则（公开数值）

- 初始：算力 30，等级 1，核心 100/100。人口 = 等级，上限 9。
- 收入：每回合基础 5 + 利息（每 10 算力 +1，上限 5）+ 连胜≥2 时 +1。
- 经验：升到 2/3/4/5/6/7/8/9 级累计需 2/6/10/18/28/40/54/70 经验。
- 合成：同名同星 3 张自动合成高一星，属性倍率 1 星 ×1、2 星 ×1.8、3 星 ×2.9。
- 出售：1 星原价，2 星 = 3 张价 −1，3 星 = 9 张价 −2。
- 商店：每回合 5 张，招募走的格子在刷新/下一回合前保持为空；刷新 2 算力并返还未购卡回卡池。
- 商店费用概率随等级提升（1 费在低等级占优，5 费只在高等级常见）。
- 模块：开局超频芯片/纳米装甲各 1 个，每 3 回合补给 1 个（轮换）；每单位最多 3 个。
- 协议（按部署动态计算）：量子密钥 2/4/6、零信任架构 2/4/6、分布式网络 2/4/6、混沌协议 2/4/6，效果见游戏左侧面板与 `src/game/synergy.ts`。
