# 黑客世界 Hacker World · 网页自走棋

原创科幻自走棋游戏：组建数字战队，在虚构网络空间与 AI 对手自动攻防。
**全部攻防均为游戏内虚构机制，不连接真实目标，不执行真实网络攻击。**

## 启动方式

```bash
cd hacker-world
npm install
npm run dev        # 打开 http://localhost:5173/
# 或只看构建产物：
npm run build && npm run preview
```

离线单文件版（已生成，可直接用浏览器打开，无需服务器）：
`dist-single.html` —— 由 `dist/` 内联 CSS/JS 生成，功能与构建版一致。

## 操作指南

1. 点击商店卡片购买单位（扣算力，进备战区 9 格）。
2. 点击备战区单位选中，再点击部署区空格部署；选中后点另一格可交换位置。
3. 点击「开始战斗」：双方自动攻防（移动、寻敌、普攻、能量攒满放技能、护盾/治疗/持续伤害/眩晕、死亡判定）。
4. 胜负结算：伤害 = 3 + 存活单位数，扣对方核心完整度；核心先归零者败。超时 60 秒按剩余生命判定。
5. 回合结束自动发收入并进入下一回合，AI 阵容随回合变强。
6. 右侧可出售选中单位、给选中单位装备模块；底部可刷新商店（2 算力）、购买经验（4 算力 = +4 经验）。
7. 「保存 / 读取」用浏览器本地存储；「重新开始」开新局。

## 核心规则（公开数值）

- 初始：算力 30，等级 1，核心 100/100。人口 = 等级，上限 9。
- 收入：每回合基础 5 + 利息（每 10 算力 +1，上限 5）+ 连胜≥2 时 +1。
- 经验：升到 2/3/4/5/6/7/8/9 级累计需 2/6/10/18/28/40/54/70 经验。
- 合成：同名同星 3 张自动合成高一星，属性倍率 1 星 ×1、2 星 ×1.8、3 星 ×2.9。
- 出售：1 星原价，2 星 = 3 张价 −1，3 星 = 9 张价 −2。
- 商店：每回合 5 张，买走的格子在刷新/下一回合前保持为空；刷新 2 算力并返还未购卡回卡池。
- 商店费用概率随等级提升（1 费在低等级占优，5 费只在高等级常见）。
- 模块：开局超频芯片/纳米装甲各 1 个，每 3 回合补给 1 个（轮换）；每单位最多 3 个。
- 协议（按部署动态计算）：量子集群 2/4/6、零信任 2/4/6、分布式网络 2/4/6、混沌协议 2/4/6，效果见游戏左侧面板与 `src/game/synergy.ts`。

## 单位（16 个）

| 费用 | 单位 | 定位 | 协议 |
|---|---|---|---|
| 1 | 闪袭者 / 哨兵节点 / 修复蜂 | 突袭 / 防御 / 修复 | 量子 / 零信任 / 分布式 |
| 2 | 幽灵刃 / 铁壁 / 数据牧师 | 突袭 / 防御 / 修复 | 混沌 / 零信任 / 量子 |
| 3 | 脉冲法师 / 堡垒核心 / 追踪者 | 分析 / 算力核心 / 分析 | 量子 / 零信任 / 分布式 |
| 4 | 超频核心 / 病毒使 / 镜像体 | 算力核心 / 混沌 / 混沌 | 量子 / 混沌 / 分布式 |
| 5 | 主宰 AI / 末日协议 / 圣殿守护 / 深渊之眼 | 算力核心 / 混沌 / 防御 / 分析 | 量子+分布式 / 混沌 / 零信任 / 混沌 |

每个单位都有独立的生命/攻击/攻速/射程/护甲与技能（爆发、范围、治疗、护盾、眩晕、增益、持续伤害、处决、混沌随机）。

## 目录结构

```
src/game/types.ts    类型、人口/经验常量
src/game/units.ts    16 单位 + 4 模块定义
src/game/synergy.ts  4 协议计算与加成
src/game/shop.ts     卡池、抽卡概率、经验
src/game/engine.ts   战斗引擎（可无头复现，见 simulateBattle）
src/game/ai.ts       AI 按回合成长与布阵
src/game/state.ts    回合/资源/存档/购买/出售/合成/装备
src/main.ts          科技风 UI（顶部/左侧/中央/右侧/底部商店）
tests/game.test.ts   自动化测试（vitest）
tests/browser-test.mjs  同机无头 Chromium 实测脚本
```
